# 🚀 Projetos DevStart (Senai)

Este repositório reúne projetos desenvolvidos durante o curso **Dev Start** do **Senai**. Cada pasta contém um projeto independente, focado em conceitos práticos de **HTML**, **CSS**, **JavaScript** e boas práticas de desenvolvimento web.

---

## 📁 Estrutura do Repositório

Cada pasta é um projeto autônomo, com sua própria lógica, estilos e documentação (quando disponível).

- `agencia-de-viagens/` – Landing page interativa para agência de viagens (modais, formulário, responsividade, animações).
- `dados-atletas/` – Demonstração de manipulação de dados de atletas (JavaScript) com interfaces básicas.
- `notas-atletas/` – Sistema simples de notas para atletas (calculadora de médias, listagem, validação).
- `postagem-de-blog/` – Simulador de publicação de posts (API fake, armazenamento local, feed dinâmico).

---

## ▶️ Como Usar

Cada projeto é independente e pode ser executado abrindo o `index.html` correspondente no navegador.

### Opção 1: Abrir diretamente

1. Navegue até a pasta do projeto desejado.
2. Abra o arquivo `index.html` no navegador.

### Opção 2: Servidor local (recomendado)

```bash
# Navegue até a pasta do projeto desejado
cd agencia-de-viagens

# Com Python 3
python -m http.server 8000

# Com Node.js (http-server)
npx http-server
```

Acesse: `http://localhost:8000`
